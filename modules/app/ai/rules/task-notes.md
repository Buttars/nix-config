# Task Notes

- `.kiro/notes.md` is a shared scratch file for work that spans multiple sessions or hand-offs — it is read into context on startup
- Append findings that would otherwise have to be rediscovered; do not restate the task
- Every factual claim carries a `file:line` citation
- Mark each claim `verified:` (you ran the command or read the file) or `inferred:` (reasoned, untested)
- Never promote an existing `inferred:` claim to `verified:` without re-checking it
- Prefer pointers over transcription — cite the path to read rather than pasting a summary of it; re-reading a file is cheap, re-deriving a conclusion is not
- Record conclusions and dead ends, not raw file contents
- Write nothing if there is nothing that would need rediscovering
