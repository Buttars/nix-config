# Tech Stack Defaults

These are personal preferences — always defer to what the project already uses.

## Languages by Domain

- CLI tools: Go, Rust, bash, Node
- Scripting: bash first, then Node or Python — never assume Python is globally installed
- Data/ML: Python, Nushell

## Databases

- Relational: Postgres, SQLite — avoid MySQL
- NoSQL: Redis, MongoDB
- ORM: project-dependent

## CI/CD

- GitHub Actions

## Cloud

- AWS or self-hosted

## Containers

- Docker or Podman depending on the system — don't assume one or the other

## Package Managers

- JS: pnpm for personal projects, npm for work
- Task runners: make, just, or npm scripts — project-dependent

## Migrations

- Project-dependent
