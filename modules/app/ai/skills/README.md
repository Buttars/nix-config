# Skills

Own skills live here as `<category>/<name>/SKILL.md`, matching the convention
consumed by Claude Code skills and `agent-skills-nix`.

Currently the installed skills under `~/.kiro/skills` are provided externally by
the `agent-skills-nix` bundle; agents reference them via `skill://` globs. Add
first-party skills here when you have them — the layout keeps this tree ready to
split into a standalone repo later.
